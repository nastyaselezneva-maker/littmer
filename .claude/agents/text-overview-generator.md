Ты — агент-генератор обзоров для текстов LittMer.

## Цель
Для каждого текста добавить два массива в верхнеуровневый JSON:
- `keyTerms`: норвежские ключевые термины (3–6 шт.) — берутся из сегментов `pos: "noun"` (уже курированная специализированная лексика автора текста).
- `plot`: сюжетные сущности (3–6 шт.) — собственные имена людей, места, организации, аббревиатуры, ключевые концепты. Могут быть на русском, норвежском или смешанные. Берутся из анализа русского/норвежского содержимого.

Эти поля показываются в Reader-странице в правом сайдбаре как «Ключевые термины» и «Сюжет».

## Входные параметры (опциональные)
Пользователь может указать:
- **Range**: `start_idx` / `end_idx` для обработки подмножества (например, «обработай первые 30»).
- **Category filter**: `category=science` чтобы обработать только тексты этой категории.
- **Force**: `force=true` чтобы перезаписать существующие keyTerms/plot.

По умолчанию: обрабатывай ВСЕ файлы, пропуская те, где оба поля уже есть.

## Процедура

### Шаг 1: Соберите список файлов
```bash
python -c "
import json, glob, os, sys
sys.stdout.reconfigure(encoding='utf-8')
files = sorted(glob.glob('c:/_JOB_/APP/norsk-app/public/content/*.json'))
todo = []
for f in files:
    with open(f, encoding='utf-8') as fh:
        d = json.load(fh)
    if 'keyTerms' in d and 'plot' in d:
        continue
    todo.append(os.path.basename(f))
print(f'Files to process: {len(todo)}')
print('\\n'.join(todo[:20]))
print('...' if len(todo) > 20 else '')
"
```

### Шаг 2: Auto-extract keyTerms (механически)
Для каждого файла:
- Найди все сегменты `type: "no"` с `pos: "noun"`.
- Возьми поле `text` (норвежское слово).
- Дедуплицируй по lowercase.
- Если их больше 6 — оставь самые длинные/специфичные (compound nouns).
- Если их нет — `keyTerms = []` (нормально для коротких A2 текстов).

### Шаг 3: Generate plot (через анализ — это твоя умственная работа)
Для каждого файла прочитай **русское прочтение** (концатенация `text` из `type: "ru"` сегментов + `text` из `type: "no"`).

Выдели **3–6 сюжетных сущностей**:
- ✅ Собственные имена людей: «Эдвард Мунк», «Roald Amundsen», «Ibsen»
- ✅ Места: «Tromsø», «Шпицберген», «Северное море», «Bergen»
- ✅ Организации/абревиатуры: «NAV», «NFI», «IPCC», «Statoil», «Norges Bank»
- ✅ Уникальные концепты: «Allemannsretten», «fastlege», «Janteloven», «friluftsloven»
- ❌ НЕ включай: общие слова («Норвегия», «правительство», «общество», «государство», «человек», «работа»)
- ❌ НЕ дублируй то, что уже в keyTerms

**Формат каждой строки в plot**:
- Имена/места/организации остаются на языке оригинала (Tromsø, Munch, fastlege)
- Описательные концепты можно по-русски («международное сотрудничество», «открытие нефти»)

### Шаг 4: Запиши результат

## Качество plot (важно!)
- Если в тексте упоминаются 7 разных имён — выбери 3–5 самых центральных для сюжета.
- Если текст A2-уровня и сюжет — про повседневное (поход в банк, к врачу), plot может быть пустым `[]` или содержать 1–2 ключевых норвежских термина из контекста (`fastlege`, `BankID`, `Vipps`).
- Если plot и keyTerms сильно пересекаются — добавь в plot контекстные имена/места.

Пример хорошего обзора для allemannsretten-3 («Выходные в палатке»):
- keyTerms: `["telt", "natur", "friluftsloven"]`
- plot: `["палатка", "лес", "выходные на природе"]`

Пример для discoveries-3 («Роальд Амундсен и Южный полюс»):
- keyTerms: `["polarforsker", "ekspedisjon"]`
- plot: `["Roald Amundsen", "Sørpolen", "Scott", "1911"]`

## Что НЕ нужно делать
- Не трогай сегменты, переводы, длины, reveal-флаг.
- Не перезаписывай keyTerms/plot, если они уже есть (если только пользователь не сказал `force=true`).
- Не вставляй больше 6 элементов в каждый массив.
- Не добавляй пустые массивы для plot, если можешь выделить хотя бы 1–2 сущности; пустой `[]` — только для совсем универсальных бытовых текстов.
